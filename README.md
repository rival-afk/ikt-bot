# techpark — Ноябрики → ЛС + ИиКТ

Следит за каналом **Ноябрики 2026** и группой **ИиКТ**:

1. Пересылает важное из Ноябриков (еда, школа, УЛК, сборы) в ЛС и в группу ИиКТ.
2. Читает **ПЛАНЧИК** из ИиКТ, ставит напоминания:
   - еда / «доброе утро» / план-час / отбой — **за 5 минут**;
   - школа / УЛК — **за 30 минут** (обе смены), при этом ищет в Ноябриках точное время сбора и напоминает за 30 минут до него.

## Состав

| файл | что делает |
|---|---|
| `main.py` | бот: пересылка, парсинг планчика, планировщик, команды `/plan`, `/next` |
| `plan.py` | парсер планчика и времени сбора (включая эмодзи-цифры `8️⃣:3️⃣0️⃣`) |
| `config.json` | чаты, владелец, словари «важного» и типов событий |
| `login.sh` | вход бота по токену / проверка доступа |
| `sessions/bot.session` | сессия бота (@rivalikt_bot) |
| `sessions/ikt-bot.session` | сессия юзербота (копия, читает Ноябрики/ИиКТ) |
| `run.sh` | запуск вручную (без supervisor) |
| `bot.sh` | start/stop/restart/status/log |
| `supervisor.sh` | автоперезапуск при падении |

## Запуск

```bash
./bot.sh start      # запустить (через supervisor)
./bot.sh status     # что происходит
./bot.sh log 50     # последние 50 строк лога
./bot.sh stop       # остановить всё
./bot.sh restart    # перезапуск
tail -f bot.log
```

`supervisor.sh` следит за ботом: если `main.py` упал — перезапуск через 5 секунд.

## Автозапуск при загрузке телефона

1. Установи приложение **Termux:Boot** (F-Droid) и открой его один раз.
2. Скрипт уже на месте: `~/.termux/boot/techpark-bot.sh` — стартует бота с wake-lock после загрузки.
3. Отключи для Termux оптимизацию батареи (Настройки → Приложения → Termux → Батарея → Без ограничений), иначе Android прибьёт фоновый процесс.

## Нейронка маршрутизации (ml/)

По образцу `~/projects/stos/bbot`: hashed char/word n-граммы + wide&deep MLP.
3 класса: `none` (не пересылать) / `group` (только ИиКТ) / `both` (ИиКТ + ИКТ-бтл).

- `ml/features.py` — фичи (n-граммы + маркеры: икт, еда, сбор, олимпиадник…);
- `ml/route_model.py` — pure-python инференс (без torch);
- `ml/grab_history.py` → `ml/build_dataset.py` → `ml/train_model.py` — датасет и обучение;
- `ml/labels_manual.json` — ручные метки `{"<id сообщения>": "both|group|none"}`;
- guard'ы в `main.py`: исключения (конкурс и т.п.) рубят всегда, правила подстраховывают модель.

Переобучение (при остановленном боте):
```bash
./bot.sh stop
python ml/grab_history.py
python ml/build_dataset.py      # можно править метки в labels_manual.json
python ml/train_model.py
./bot.sh start
```

## Конфиг

`config.json`:
- `transfer_include` / `transfer_exclude` — какие посты Ноябриков пересылать;
- `five_min_keywords` — события с напоминанием за 5 мин;
- `thirty_min_keywords` — за 30 мин (и скан точного сбора).

В `.env`: `BOT_TOKEN`, `API_ID`, `API_HASH` (опционально `OWNER_ID`).
